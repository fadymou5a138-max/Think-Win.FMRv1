مسابقة المعرفة الكبرى — Think & Win FMR

الملفات المضافة/المحدثة:
- manifest.json: تعريف التطبيق القابل للتثبيت PWA.
- sw.js: تخزين ملفات التطبيق الأساسية لدعم الفتح دون اتصال بعد أول تحميل ناجح.
- icon-192.png و icon-512.png: أيقونات PWA.
- favicon.svg: أيقونة المتصفح.
- og-image.png: صورة المشاركة الاجتماعية (1200×630).
- تحديث index.html: بيانات SEO وOpen Graph وربط Manifest والأيقونات وإضافة إحصائيات الجولات.
- تحديث script.js: تسجيل Service Worker وحفظ نتائج الجولات محليًا.
- تحديث style.css: تنسيق الإحصائيات وتحسين احترام إعداد تقليل الحركة.

النشر:
1) ارفع جميع الملفات والمجلدات كما هي إلى جذر مستودع GitHub Pages.
2) افتح الموقع باستخدام HTTPS، وليس بفتح index.html مباشرة من الجهاز.
3) افتح الموقع مرة مع اتصال بالإنترنت وانتظر حتى يكتمل التحميل، ثم أعد فتحه لاختبار وضع عدم الاتصال.
4) على Chrome/Edge استخدم Install app / تثبيت التطبيق عند ظهور الخيار. قد تختلف إتاحة التثبيت حسب المتصفح والجهاز.

ملاحظات مهمة:
- حفظ النتائج يعمل محليًا على نفس المتصفح والجهاز باستخدام localStorage، وليس بين أجهزة مختلفة.
- لوحة ترتيب مشتركة، تسجيل دخول، مزامنة سحابية، أو إدارة مستخدمين تحتاج Backend وقاعدة بيانات.
- صورة Open Graph قد لا تظهر في بعض منصات التواصل عند استخدام رابط نسبي؛ الأفضل بعد النشر وضع رابط كامل للصورة في og:image.
- يجب مراجعة صحة الأسئلة علميًا وتاريخيًا قبل استخدام المسابقة في حدث رسمي.
